# Buffers.nvim
Dead simple and efficient buffer switcher and manager with plenty of customization. 

![screenshot](https://github.com/user-attachments/assets/8fa2a8d9-27e4-468d-835e-3a1a2387de4a)


Single key is assigned to each buffer.
On trigger, these mappings are displayed in floating window and on keypress custom function is run with selected buffer. Window is closed.

> There's bit more to it so,
